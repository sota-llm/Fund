# Fund

本地、可重复运行的硬科技基金观察工具，覆盖 CPO、半导体、PCB、MLCC。默认不需要安装第三方 Python 包。

## 启动

```bash
cd Fund
./run.sh
```

浏览器会打开 <http://127.0.0.1:8765/dashboard.html>。首页先展示 10 只基金的统一口径总览；点击任一基金，才会生成该基金的完整分钟线、最近 30 个交易点和持仓明细。

也可手动运行：

```bash
# 只刷新一次总览
python3 multi_monitor.py refresh

# 启动持续服务
python3 multi_monitor.py serve --port 8765 --open

# 保留的原单基金数据源检查
python3 monitor.py doctor
```

## 观察池

观察池定义在 `funds.json`，依据 2026 年二季报披露的前十大持仓选择，不是基金推荐或收益排名：

- CPO：华商优势行业、财通科技创新、红土创新新科技等。
- 半导体：银华集成电路、平安半导体领航精选、华富半导体产业、长城半导体等。
- PCB：财通科创主题，以及持有 PCB/覆铜板环节的混合基金。
- MLCC：披露持有三环集团、风华高科等被动元件标的的基金。

主题标签与披露前十的直接主题权重只用于解释观察池，不代表基金全部资产的行业分类。

## 刷新架构

```text
低频资料层（每6小时）
  └─ 10只基金的正式净值、股票仓位、最新披露前十持仓

共享行情层（每30秒）
  ├─ 将全部披露持仓按股票代码去重
  ├─ 东方财富一次批量报价
  └─ 腾讯一次批量报价交叉核验

按需详情层（点击具体基金）
  ├─ 该基金的完整09:30—11:30、13:00—15:00分钟线
  └─ 最近30个交易点的正式净值、沪深300和披露前十模拟组合
```

当前 10 只基金共有 96 条披露持仓，去重后为 58 只股票；常态行情刷新只需两次批量请求。分钟线不在后台为所有基金反复抓取，休市后生成的详情缓存 6 小时。

## 估值口径

所有基金使用同一套透明模型：

```text
前十直接贡献 = Σ（披露持仓占净值 × 个股今日涨幅）
前十内部涨幅 = 前十直接贡献 ÷ 前十合计权重
模型日涨幅 = 前十内部涨幅 × 最近披露股票仓位
T日预估净值 = T−1日正式净值 ×（1 + T日模型日涨幅）
```

T 日预测只从 T−1 日正式净值延伸一次；新正式净值公布后重新起算，不连续叠加预测。

## 数据源与边界

- 天天基金/东方财富基金档案：正式净值、股票仓位、最新披露前十大持仓。
- 东方财富行情：批量实时行情主源。
- 腾讯行情：实时行情交叉核验、个股分钟线与历史日线。

开放式基金没有公开、官方的盘中实时净值。季报后换仓、前十以外资产、港股、现金、债券、费用和申赎冲击都无法被完整还原，因此页面显示的是模型估算，正式结果以基金公司披露为准。公开接口也没有付费 SLA；代码使用批量请求、双源核验、本地缓存和按需详情降低限流与中断风险。
